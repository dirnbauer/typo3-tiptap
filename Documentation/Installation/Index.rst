============
Installation
============

Requirements
============

-  TYPO3 CMS 14 LTS
-  PHP 8.3 or newer
-  ``EXT:rte_ckeditor``

Composer
========

..  code-block:: bash

    composer require in2code/typo3-tiptap

Optional workspace support
==========================

Install and enable ``EXT:workspaces`` if your editorial workflow uses staged content changes and approvals.
